# RAG Chatbot
A PDF question-answering chatbot built with LangChain, FAISS, HuggingFace Embeddings and Groq LLM.

🚀 **Live Demo:** [Click here](https://your-streamlit-url.streamlit.app)

## How to use
1. Upload a PDF
2. Type your question
3. Get answers!

## Tech Stack
- Streamlit
- LangChain
- FAISS
- HuggingFace Embeddings
- Groq LLM
